# WolfBBS Next 50 Roadmap

This document defines the next 50-product-improvement backlog after the original `docs/ROADMAP_50.md` set.

## Delivery rule
- Ship in coherent, validated tranches.
- Every tranche ends with unit tests, browser validation, verifier pass, and a packaged release.
- Items are ordered by product leverage, not by implementation convenience.
