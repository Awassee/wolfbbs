## Refresh Workflow

From repo root:

```bash
scripts/capture-doc-screenshots.sh
```

The script will:

1. start a Playwright-driven local web instance
2. capture key product surfaces
3. write PNG files into this directory
4. generate `getting-started.gif` when Python `Pillow` is available
