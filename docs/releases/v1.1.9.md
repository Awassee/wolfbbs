# WolfBBS v1.1.9

Release date: 2026-03-17

## Highlights

This release is a full UI/UX/product pass focused on the highest-friction daily workflows rather than new route sprawl.

### Top improvements shipped
1. Dismissible styled page banners for notices and errors across the web UI.
2. Shared copy-to-clipboard actions for command blocks and operator snippets.
3. Active-filter summaries and reset affordances for high-traffic filtered pages.
4. Local draft autosave, restore, and unsaved-change protection for compose/reply/menu-editor workflows.
5. Safer destructive admin actions via confirmation prompts and double-submit protection.
6. Better Connect page onboarding with clipboard-ready commands, connection sanity details, and troubleshooting guidance.
7. Better Boards UX with active-filter summaries, board-scan guidance, reader helper cards, and draft-aware posting/reply flows.
8. Better Mail UX with triage guidance, active-filter summaries, and draft-aware compose/reply flows.
9. Stronger sysop/operator surfaces in Status, Launch, Setup, and Runtime Config with clearer next actions and better guidance.
10. Better admin user-management usability with clearer guidance and filter visibility.
