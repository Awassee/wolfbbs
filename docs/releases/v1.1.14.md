# WolfBBS v1.1.14

## Summary
This release starts the next ordered 50-item roadmap tranche with faster day-to-day workflow features for callers, moderators, and sysops.

## Shipped
- New roadmap extension in `docs/ROADMAP_NEXT_50.md`
  - defines items `51` through `100`
  - marks the first tranche as shipped in `v1.1.14`
- Read-later queue at `/bookmarks`
  - save board posts for later
  - save private mail for later
  - remove individual saved items or clear the queue
- Handle assist for web composition and chat
  - local handle suggestions for mail recipients
  - `@mention` suggestions in board posts and chat
  - keyboard and click selection
- Richer presence surfaces
  - `/directory` now shows node, idle time, and caller origin details when online
  - `/chat` now renders presence cards instead of a flat caller list
- Moderation triage hints in `/admin/boards`
  - duplicate-content hints
  - report-count hints
  - thread-size hints
  - direct links into the reported message when available
- File preview surfaces in `/gateway?view=files&id=<id>`
  - metadata summary
  - SHA-256 and tags
  - related uploads
  - queue and ticket actions from preview context
- Tournament center improvements in `/tournaments`
  - standings table
  - bracket preview seeded from recent champions
