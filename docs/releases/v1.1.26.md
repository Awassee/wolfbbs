# v1.1.26

WolfBBS v1.1.26 is a security, performance, and public-release hardening cut. The product surface stays the same, but several important backend and operator-facing safeguards are stronger in this release.

## Highlights

- Hardened the AI gateway so it no longer accepts arbitrary private or loopback base URLs by default.
- Added bounded admin file uploads with a configurable max size and an optional policy/scanner hook.
- Reduced unnecessary chat presence polling work in hidden browser tabs.
- Updated the operator docs and environment reference so the new safeguards are visible and configurable.

## Release-blocking fixes included

- AI gateway base URLs are syntax-validated in admin configuration and fully SSRF-checked at request time.
- Private/local AI endpoints now require explicit operator opt-in via `WOLFBBS_GATEWAY_AI_ALLOW_PRIVATE=1`.
- Admin file uploads now enforce `WOLFBBS_UPLOAD_MAX_BYTES` and reject oversize payloads before they land in the file base.
- Optional upload policy hooks can reject files before indexing via `WOLFBBS_UPLOAD_POLICY_HOOK`.
- Chat presence refresh is now visibility-aware to reduce background polling load.
