# WolfBBS v1.1.13

## Summary
This release ships the next ordered roadmap tranche focused on onboarding, launch readiness, and daily-use clarity.

## Shipped
- Guided `/first-call` session for new callers
  - starter board post
  - starter lobby message
  - starter private mail
  - saved home-route selection
- Guest and caller onboarding polish
  - guest quick-start checklist on `/start`
  - caller quick-start checklist on `/today`
  - first-caller progress surfaced from `/start`
- Saved home-route preference in `/settings`
  - `/today`, `/boards`, `/chat`, or `/doors`
  - root, login, and connect redirects now honor the saved preference
- Sysop launch hardening in `/admin/launch`
  - persisted go-live checkpoints
  - explicit rollback steps
  - audit trail on checkpoint changes
- Role-aware empty states across major surfaces
  - boards
  - board detail
  - chat
  - new files
  - doors
- Roadmap/docs alignment for the shipped tranche
