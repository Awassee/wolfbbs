# v2.1.0

WolfBBS v2.1.0 is the long-lived stability release for the 2.x line. This cut focuses on operator-safe upgrades, terminal resilience, and public-release hardening rather than headline feature churn.

## What changed

- Hardened the installer and runtime verification path for real-world custom-port installs.
  - Installer verification now reads runtime ports from the installed `.env` instead of assuming defaults.
  - macOS/Colima upgrades continue healing mount-unsafe Docker socket paths into `/var/run/docker.sock` during upgrade and repair.
- Strengthened terminal resilience.
  - added reconnect notices for interrupted sessions
  - added session output mode overrides (`auto`, `color`, `plain`)
  - improved cursor editing, delete/backspace handling, and live resize behavior
- Added public release readiness material.
  - `SECURITY.md` now documents vulnerability reporting and disclosure expectations.
  - stable release validation now includes a lifecycle matrix that exercises baseline install failure recovery, upgrade, rapid-upgrade, repair, rollback, restore, clean uninstall, and clean reinstall.

## Release scope

This release is intended to be the stable public build operators can leave in place for an extended period, with a stronger recovery path and less fragile terminal behavior than the earlier v2.0.x cuts.
