# v2.1.3

- Fixed packaged-installer bundle resolution for canonical GitHub repo URLs ending in `.git`, so bundle-first installs no longer fall back to `git clone` unnecessarily.
- Fixed release tarball runtime packaging so Docker installs use Linux container binaries from `container-bin/` while still preserving host binaries in `bin/`.
- Hardened installer regression coverage around GitHub slug parsing, non-interactive macOS runtime setup, and packaged bundle lifecycle checks.
- Made the terminal acceptance harness seed a readable board up front so the end-user SSH journey stays deterministic on clean and reused test databases.

Validation highlights:

- `bash scripts/test-installer-regressions.sh`
- `scripts/verify.sh --fast`
- local packaged bundle build for `darwin/arm64`
- real standalone bundle install, health checks, `--status`, and clean uninstall on macOS
