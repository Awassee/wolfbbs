# v1.1.25

WolfBBS v1.1.25 is the corrected public distribution cut. It keeps the same validated product surface from the recent UX and stability work, and fixes the release pipeline so the public download set now matches the documentation and operator expectations.

## Highlights

- Ships the public distribution as a full four-platform bundle set:
  - `linux/amd64`
  - `linux/arm64`
  - `darwin/amd64`
  - `darwin/arm64`
- Preserves the refined web UX, dense-route polish, mobile quick tools, and visual regression coverage already validated on the current mainline.
- Keeps release notes, README, install docs, showcase, datasheet, and release index aligned to one public tag.

## Release-blocking fixes included

- Fixed release automation so default public releases package the full supported platform matrix instead of only the local host platform.
- Fixed release automation staging so `dist/` additions and removals are committed cleanly between release versions.
- Carried forward the current green validation baseline and refreshed acceptance evidence for the public handoff.
