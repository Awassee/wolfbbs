# v2.0.2

WolfBBS v2.0.2 is the open-source licensing follow-up on the 2.0 line. This release adds a first-class MIT license, contribution guidance, distribution licensing artifacts, and container metadata so the public repo and packaged builds are cleanly consumable as open-source software.

## What changed

- Added a top-level MIT [LICENSE](../LICENSE) for GitHub license detection and downstream distribution clarity.
- Added [CONTRIBUTING.md](../../CONTRIBUTING.md) with validation expectations and contribution-under-MIT terms.
- Added [docs/OPEN_SOURCE.md](../OPEN_SOURCE.md) to document licensing scope, packaged notices, and third-party dependency considerations.
- Updated the public docs to surface the project license and contributing guidance more clearly.
- Added OCI image license metadata so container consumers can identify the project license programmatically.
- Updated distribution packaging so release bundles include `LICENSE`, `CONTRIBUTING.md`, and the open-source guide.

## Validation

This release is validated with:

- `bash -n scripts/package-dist.sh scripts/release.sh install.sh bootstrap.sh`
- `scripts/package-dist.sh --help`
- `go test ./...`
- `scripts/verify.sh --fast`

## Artifacts

Release bundles, checksums, and manifest are published from `dist/v2.0.2/`.

## Notes

- This release is intentionally narrow and focused on open-source readiness.
- The unrelated in-progress UI/terminal work in the main development worktree is not part of `v2.0.2`.
