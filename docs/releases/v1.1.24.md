# v1.1.24

WolfBBS v1.1.24 is the corrected public distribution cut after v1.1.23. It keeps the same validated product surface, but fixes the release payload so public downloads match the platform matrix the docs advertise.

## Highlights

- Ships the public distribution as a full four-platform bundle set:
  - `linux/amd64`
  - `linux/arm64`
  - `darwin/amd64`
  - `darwin/arm64`
- Keeps the latest web UX and dense-route polish from the v1.1.23 line.
- Preserves the current green validation baseline across tests, smoke checks, browser flows, and automated acceptance.

## Release-blocking fixes included

- Fixed release automation so a default public release now packages the full platform matrix instead of only the local host platform.
- Fixed release automation staging so `dist/` additions and removals are committed cleanly between release versions.
- Carried forward the public-doc refresh so README, install docs, showcase, datasheet, and release index all point at the current shipped tag.
