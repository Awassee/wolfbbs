# WolfBBS v1.1.3

This release packages WolfBBS more clearly as a product.

## What changed

- rewrote the root `README.md` so GitHub explains:
  - what WolfBBS is
  - who it is for
  - what features it includes
  - how to install it quickly
  - what to do immediately after first launch
- added a product-facing guide in `docs/PRODUCT_GUIDE.md`
- added a deployment and capability summary in `docs/DATASHEET.md`
- expanded `docs/QUICKSTART.md` and `docs/INSTALL.md` with first-run and operator-oriented guidance
- updated `scripts/package-dist.sh` so release bundles include the new product docs

## Why it matters

New users landing on GitHub now get a usable product narrative instead of only implementation details. Release bundles also carry the same onboarding and positioning material, so packaged downloads are easier to evaluate and operate.
