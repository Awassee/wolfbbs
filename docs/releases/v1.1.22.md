# v1.1.22

WolfBBS v1.1.22 turns the post-v1.1.21 stabilization tranche into a release. The focus of this cut is reliability, coverage, and operator readiness rather than headline UI churn.

## Highlights

- Deepened SSH/TUI functional coverage with robust end-to-end traversal across caller and sysop flows.
- Expanded IRC integration coverage to verify JOIN/PART/KICK behavior, welcome numerics, and multi-client parity.
- Hardened the installer lifecycle for repair, uninstall, and rapid upgrade scenarios.
- Added release automation so packaging, notes, tagging, and GitHub release creation can be repeated cleanly.
- Added operator-oriented docs for first-run setup and community operations.
- Added operator insights and first-call analytics for onboarding and feedback visibility.
- Improved credential handling in the web admin so temporary credentials are shown through one-time receipts instead of raw action responses.

## Release-blocking fixes included

- Fixed brittle terminal automation around line-vs-key prompts, pagers, quick-jump parity, and admin desk traversal.
- Fixed quick-jump route handling so `collections` and `offline` open their dedicated SSH surfaces directly.
- Fixed IRC peer event propagation for PART/KICK paths and aligned smoke verification with authenticated multi-user coverage.
- Fixed installer regression gaps around `--repair`, `--status`, and clean uninstall behavior.
