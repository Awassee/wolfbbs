# v2.1.1

WolfBBS v2.1.1 is the final public follow-up to the v2.1.0 stable line. This release does not add feature churn. It aligns the shipped public release with the refreshed GitHub screenshots and hardens the release process so future public cuts stage those assets automatically.

## What changed

- Refreshed the public screenshot set used by the README, showcase, and GitHub-facing product materials.
  - updated core surfaces: connect, boards, chat, doors, today, and getting-started animation
- Hardened release automation.
  - `scripts/release.sh` now stages `docs/assets/screenshots` as part of the ship commit so docs assets do not drift from the tagged release

## Why this release exists

v2.1.0 was the correct stable runtime cut, but `main` moved one small step ahead with refreshed public-facing assets and a release-tooling safeguard. v2.1.1 brings the public tag up to the same state as the repo head so operators, visitors, and release artifacts all point at the same product presentation.
