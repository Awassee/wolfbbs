# WolfBBS v1.0.0

Release date: 2026-03-19  
Channel: consumer-ready distro baseline

## Summary

`v1.0.0` is the packaged baseline intended for public distribution from GitHub.

It locks in:

- SSH-first ANSI caller experience with modern web companion parity
- installer-first lifecycle (`install`, `upgrade`, `repair`, `uninstall`)
- multi-protocol access (SSH + Web + IRC + mail ingress + gateway surfaces)
- reproducible release bundles with checksums/manifests
- updated GitHub-facing product pages and docs hub

## Included Product Areas

- Caller flow: `/today`, `/boards`, `/mail`, `/chat`, `/doors`, `/scores`
- Operator flow: `/admin/setup`, `/admin/launch`, `/admin/config`, `/admin/ops`, `/admin/release`
- Community loop: `/events`, `/events/recaps`, `/challenges`, `/clubhouse`
- Distro lifecycle: `bootstrap.sh`, `install.sh`, `scripts/package-dist.sh`
