# WolfBBS v1.0.0

First consumer-ready release.

## Highlights

- SSH-first ANSI BBS with upgraded Wildcat-style terminal UX
- Modernized web surfaces for boards, mail, finder, new-files, directory, chat, doors, and sysop setup
- Installer-first deployment flow for Linux and macOS
- Multi-protocol access surfaces: SSH, web, IRC, mail ingress, gateway, and doors
- Packaged distribution bundles with checksums

## Release Notes

- Daily-use caller workflows were deepened across boards, mail, finder, new-files, and directory.
- ANSI menu rendering and narrow-terminal behavior were tightened for more consistent SSH/TUI sessions.
- Web UX now includes stronger navigation, cockpit pages, and classic-modern surfaces such as Bulletin Center, Caller Directory, Message Finder, and New Files Desk.
- Installer, docs, verification, and packaging paths were revalidated for GitHub-based consumer delivery.
