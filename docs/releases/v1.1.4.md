# WolfBBS v1.1.4

This release is a project scrub focused on usability and product clarity.

## Highlights

- stronger GitHub-facing product copy in the root README
- new `START_HERE.md` and `OPERATIONS.md` guides
- clearer quickstart and install guidance
- improved installer menu, first-login summary, and status output
- richer in-product help and setup guidance
- contextual web UI primers on key routes

## Why it matters

WolfBBS now does a better job of telling new operators:

- which install path to choose
- what to do immediately after the stack comes up
- which surfaces matter to callers vs sysops
- how to recover or operate the board after the first install
