# v2.0.1

WolfBBS v2.0.1 is the first public patch on the 2.0 line. This release focuses on cleaning up the shared web shell, reducing control noise on dense pages, refreshing the public docs/screenshots, and locking the new layout in with updated browser coverage.

## What changed

- Simplified the shared web shell so the primary header now favors grouped menus over always-visible control clutter.
- Moved live status and utility actions into clearer `Status`, `Route`, `Tools`, and `Help` groupings.
- Compacted legacy nav rows so high-link routes no longer show a wall of pills across the top of the page.
- Removed the generic sticky `"Submit form"` helper unless a form explicitly opts in, eliminating duplicate-action noise.
- Folded section utilities into a single `Tools` menu on dense pages and hid empty helper rails instead of filling them with placeholder copy.
- Refreshed the public screenshot set and getting-started animation to match the shipped UI.
- Updated browser regression coverage so the simplified control model is exercised directly.

## Notes

- This is a release-surface and usability hardening cut, not a feature-sprawl release.
- `v2.0.0` remains the major-version baseline; `v2.0.1` makes that line calmer and more presentation-ready for public consumption.
