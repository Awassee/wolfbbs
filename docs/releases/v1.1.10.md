# WolfBBS v1.1.10

## Summary

This release deepens the new start/attention/ops workflow and makes the compose experience materially better for real callers and sysops.

## Highlights

- Attention Center now supports actionable queue cleanup:
  - dismiss direct attention items
  - dismiss board watch items
  - mark one mail read
  - mark all mail read
  - restore dismissed items
- Attention dismissals now persist through admin system settings so they survive app restarts.
- Ops Center now includes live remediation actions:
  - clear runtime errors
  - prune idle node sessions
  - purge expired web sessions
  - clear active rate-limit buckets
- Rich compose gained:
  - preview mode
  - focus mode
  - quote-context insertion
  - signature insertion
  - saved-draft timestamps
  - keyboard shortcuts including `Ctrl/Cmd+Enter` submit and `Esc` to exit focus mode
