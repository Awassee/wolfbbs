# v1.1.23

WolfBBS v1.1.23 turns the latest UX polish and release-prep work into a clean public distribution cut. This release focuses on making the product look more intentional, keeping dense routes easier to navigate, and tightening the release materials so GitHub, docs, and packaged artifacts all describe the same shipped state.

## Highlights

- Refined the modern web shell with a stronger dark visual system, cleaner dense-route behavior, and more consistent shared utility chrome.
- Added mobile-first Quick Tools behavior so the floating action patterns remain usable on narrow screens.
- Added visual regression coverage for stable secondary routes to catch layout drift earlier.
- Extracted shared modern UI assets out of the main web entrypoint so future UI changes are lower-risk and easier to maintain.
- Hardened settings coverage with stronger 2FA/browser-flow regression testing.
- Refreshed release metadata, public docs, and release automation for a cleaner public-facing handoff.

## Release-blocking fixes included

- Fixed web-shell interaction conflicts where floating controls could interfere with omnibar access.
- Reduced dense-screen overload with progressive disclosure and compact section navigation.
- Fixed stale release references across public docs so install commands, release notes, and packaging targets stay aligned.
- Updated release automation to sync the current public release references more completely and publish GitHub releases against the selected remote explicitly.
