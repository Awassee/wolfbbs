# WolfBBS v1.1.15

## Summary
This release ships the next ordered roadmap tranche around caller continuity, live social interaction, and sysop-planned communication.

## Shipped
- Roadmap continuation in `docs/ROADMAP_101_150.md`
  - defines items `101` through `150`
  - keeps the next backlog ordered instead of ad hoc
- Theme 6 tranche from `docs/ROADMAP_NEXT_50.md` is now shipped
  - items `57` through `62`
- Bulletin Scheduler at `/admin/bulletins`
  - create, edit, and delete timed announcements
  - bulletin preview with publish window metadata
  - scheduled items flow into `/bulletins`
- Timed announcements in `/bulletins`
  - scheduled system wire entries
  - caller-facing announcement cards
- Caller Directory upgrades in `/directory`
  - favorite callers with dedicated filter lane
  - live paging to online callers
  - recurring correspondents on caller profiles
  - moderator/sysop staff notes on caller profiles
- Presence-aware communication handoff
  - `/mail?to=<handle>` now shows live presence guidance for online local recipients
  - chat presence cards link directly into page and mail follow-up
- Attention Center upgrades at `/attention`
  - live page requests appear alongside other follow-up items
  - page items include direct reply-by-mail handoff
- Hardening fixes included in this tranche
  - directory now excludes disabled and banned accounts from public/profile views
  - directory presence rows correctly render node, idle, and origin data
  - moderation hints no longer mis-group root posts under fake `thread 0`
