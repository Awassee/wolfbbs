# v2.0.0

WolfBBS v2.0.0 is the public 2.0 release. This cut turns the recent stabilization, coverage, operator tooling, and web UX cleanup work into a single consumer-ready distribution.

## What stands out in 2.0

- Simplified the shared web shell so dense pages no longer feel like a wall of competing controls.
- Grouped route, view, desk, ops, and help actions into cleaner menus and removed redundant floating utility buttons from the default desktop UI.
- Gave help and guidance copy its own visual treatment so instructions read like guidance instead of controls.
- Expanded regression coverage across installer, browser, accessibility/mobile, visual, and functional flows.
- Hardened release, audit, and operator workflows so packaging and public delivery are more repeatable.

## Product surface carried in this release

- SSH-first ANSI caller flow with boards, mail, chat, doors, scores, and sysop/admin parity.
- Modern web companion with launch, setup, config, ops, community, and caller surfaces.
- IRC bridge with shared chat state.
- Installer lifecycle covering bootstrap, install, upgrade, repair, rapid upgrade, and uninstall flows.
- Release packaging across Linux and macOS on both amd64 and arm64.
