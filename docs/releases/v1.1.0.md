# WolfBBS v1.1.0

Public release focused on installer UX, onboarding docs, and clean distribution packaging.

## Highlights

- Switched the canonical repository and release URLs to the public distribution repo.
- Added a guided no-flags installer flow with:
  - action menu
  - easy-install plan screen
  - inline customization for install directory, ports, and source repo
- Added a concise [Quickstart](../QUICKSTART.md) guide for first-time operators.
- Expanded bundled docs so release tarballs include quickstart plus install/admin/chat/door references.
- Rebuilt release artifacts from the cleaned tree for public publication.
