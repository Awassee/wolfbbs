# WolfBBS v1.1.1

Patch release focused on true one-line bootstrap install.

## Highlights

- Added `bootstrap.sh` as the public downloader/bootstrap entrypoint.
- One pasted command now downloads the installer and runs dependency/runtime setup.
- Changed standalone installs to keep runtime state in `<prefix>/` and managed source in `<prefix>/app/`.
- Fixed the old collision where standalone installs could fail on a non-empty install prefix.
- Added regression coverage for bootstrap dry-run execution in `scripts/verify.sh`.

## Validation

- `bash -n install.sh`
- `bash -n bootstrap.sh`
- `cat install.sh | bash -s -- --dry-run --yes --with-docker --prefix <temp>`
- `bash bootstrap.sh --dry-run --yes --with-docker --prefix <temp>`
- `scripts/verify.sh --fast`
