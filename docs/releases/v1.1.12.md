# WolfBBS v1.1.12

Release date: 2026-03-18

## Summary

This release ships the next roadmap tranche focused on daily follow-up control, lower-noise board tracking, richer posting UX, and recurring calendar management.

## Shipped

- Persistent Attention Center state:
  - per-user read/unread tracking
  - per-user dismiss/restore tracking
  - mark-read, mark-unread, and mark-all-read actions
- Board subscription tiers:
  - `watch`
  - `digest`
  - `mute`
- Daily brief updates:
  - watch-tier board section
  - digest-tier board section
  - subscription-aware board summaries
- Full-screen web composer:
  - preview
  - focus mode
  - fullscreen mode
  - quote context
  - insert signature
  - keyboard shortcuts help
  - persistent layout state
- Recurring community events:
  - daily, weekly, and monthly recurrence
  - repeat-until support
  - recurring event expansion in public and recent event views
- Acceptance harness fix:
  - terminal e2e now advances past the welcome splash correctly when the first detected marker is `WolfBBS Welcome`

## Validation

- `go test ./...`
- `scripts/verify.sh --fast`
- `scripts/run-e2e.sh --no-go --no-tui --web-timeout 900`
- `scripts/manual-acceptance.sh --auto --no-smoke --report docs/manual-acceptance-latest.md`
- docker-compose smoke stack startup plus live health, port, and IRC runtime checks

## Notes

- In local Docker environments where Compose bake stalls, run smoke with `COMPOSE_BAKE=false`.
