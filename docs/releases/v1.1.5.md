# WolfBBS v1.1.5

This release fixes the turnkey installer path so the public paste-and-run bootstrap no longer depends on a usable `git` client being present on the host.

## Highlights

- standalone `install.sh` now verifies that `git` is actually runnable before choosing clone/update paths
- GitHub archive download fallback is used automatically when `git` is missing or broken
- installer verification now includes a MUST-level no-`git` dry-run check
- install and quickstart docs explicitly describe the archive fallback path

## Why it matters

Operators can now use the bootstrap command on clean machines that only have `bash` and `curl` available up front. The installer is responsible for fetching WolfBBS and the rest of the dependencies.

## Validation

- `bash -n install.sh`
- `bash -n bootstrap.sh`
- `scripts/verify.sh --fast`
- standalone installer dry-run with a non-functional `git` shim in `PATH`
