# v1.1.27

WolfBBS v1.1.27 is the public-release follow-up to v1.1.26. It carries forward the gateway, upload, performance, and security hardening from v1.1.26, and fixes the release-index/docs automation so the GitHub-facing release surface stays consistent.

## Highlights

- Keeps the AI gateway SSRF hardening and explicit private-endpoint opt-in from v1.1.26.
- Keeps bounded upload intake plus optional upload policy/scanner hook support from v1.1.26.
- Keeps the visibility-aware web chat presence refresh improvement from v1.1.26.
- Corrects the release index automation so the current public release and historical list stay accurate after each ship.

## Release-blocking fixes included

- Fixed release index sync so `docs/releases/README.md` advances the current release line correctly.
- Fixed release index history insertion so the previous release remains visible after a new ship.
- Preserved the full four-platform release bundle matrix and public GitHub release asset flow.
